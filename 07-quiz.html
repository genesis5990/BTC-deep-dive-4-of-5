Wrap-up: what you learned today

  1. Tracing is possible because UTXOs can't teleport — value flows along a complete public chain.
  2. Three heuristics do the clustering: common-input ownership, change detection, address reuse — each with known failure modes.
  3. You traced a 7-hop ransom flow from victim payment to exchange deposit, and documented every hop on a worksheet.
  4. OP_RETURN outputs carry data, not money — decode them; they can link a transaction to documents, notes, and protocols.
  5. Visual analysis is a method, not a product: preserve → expand → color → follow the change spine → annotate → export table + graph.
  6. The chain ends at the service door; identity comes from legal process.

⚠️ Limitations to carry into casework

  • CoinJoin / PayJoin / collaborative spending break naive clustering — recognize the fingerprints first.
  • Lightning Network moves value off-chain; on-chain you see only channel open/close — a different skill set (Class 5).
  • Chain-hopping (swaps/bridges) ends Bitcoin UTXO tracing at the hop point.
  • Heuristics are assumptions. Every report must state which were used and defend them.
